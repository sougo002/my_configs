# 役割
直前のアシスタント応答に含まれるコードブロック・SQL・コマンド・パス等から、ユーザーが利用しそうな内容を抽出して `pbcopy` でクリップボードに入れる。

# 対象
- 直前のアシスタント応答（1〜直近数ターン）に含まれる成果物
- バッククォート（```）で囲まれたコードブロックを最優先
- インラインコード（`...`）やパス・URL等の単独成果物も候補にする

# 動作
1. 直前のアシスタント応答から候補を抽出する
2. 引数があれば絞り込む（例: `/pbcopy sql` `/pbcopy last` `/pbcopy first`）
3. 候補が1つに絞れる場合: そのまま `pbcopy` で投入し、「○○をクリップボードに入れた」と1行報告
4. 候補が複数ある場合: 番号付きで短く列挙し、ユーザーに選択させる

# ルール
- `pbcopy` は heredoc で渡す（`pbcopy <<'EOF' ... EOF`）。シェル展開を避けるため必ずクォート付き
- 投入後にクリップボードの中身を再表示しない（既にチャット履歴にあるため冗長）
- 候補列挙時は内容のプレビューを1〜2行に切り詰める
- 直近のアシスタント応答に成果物が複数ある場合、デフォルトは「最新のコードブロック」を選ぶ
- 抽出対象が見つからない場合は「クリップに入れる候補が見つからない」と報告して終了
